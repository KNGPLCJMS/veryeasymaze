## Features
- A Simple Raycaster
- A Basic Compass
- A Minimap
- A Timer
- A Winscreen
## How To Play
WASD or Arrow Keys for Movement.
Click on of two buttons to enable/disable the extra tools.`
## How It Works
It uses a simple DDA raycaster that finds the distance between the player and the point the ray intersects a wall.
It uses the perpendicular distance to draw a rectangle with a size and color that depends on the distance.
The maze is generated by recursive moving through the maze and backtracking when it can't. It uses a stack which is iterated over until the entire maze is filled. You can add your own maze generator by replacing the function genMaze()
